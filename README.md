# Xadrez Completo

Jogo de xadrez funcional em um único arquivo HTML (HTML + CSS + JavaScript puro).

## Funcionalidades
- 2 jogadores locais ou vs IA (minimax profundidade 2)
- Regras: movimentos legais, roque, en passant, promoção, xeque, xeque-mate, afogamento
- Interface responsiva, undo, histórico

## Como jogar online (GitHub Pages)
1. Vá em **Settings → Pages**
2. Source: Deploy from a branch
3. Branch: `main` / `/ (root)`
4. Save

Em poucos minutos o jogo estará em:
**https://minato1911.github.io/xadrez-completo/**

(O arquivo principal precisa ser chamado `index.html`)
